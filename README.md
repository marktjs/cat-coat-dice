# 🎲 Cat Coat Dice

An interactive feline coat genetics generator! Roll the genetic dice to explore Mendelian and X-linked cat coat traits (sex-linked orange/X-inactivation, eumelanin base, pigment dilution, agouti/tabby, white spotting, and dominant white).

🌐 **Play online:** [https://marktjs.github.io/cat-coat-dice/](https://marktjs.github.io/cat-coat-dice/)
